PORTFOLIO NDIMBY — mode d'emploi
================================

OUVRIR LE SITE
  Double-clique sur index.html (tous les fichiers du dossier doivent rester ensemble).
  Liens directs : index.html#projets, #storyboards, #services, #a-propos, #contact

LES FICHIERS
  index.html   la page
  contenu.js   ← TOUT TON CONTENU EST ICI (c'est le seul fichier à modifier)
  main.js      construit la page (pas besoin d'y toucher)
  style.css    l'apparence
  assets/      photo, CV, police, storyboards, et plus tard tes vidéos

AJOUTER TES VIDÉOS (dans contenu.js → projects)
  video   : 'assets/videos/clip.mp4' ou un lien YouTube / Vimeo
            → la vidéo se lit dans la fiche du projet.
  preview : petit extrait MP4 muet de 3-5 s ('assets/videos/clip-apercu.mp4')
            → joué au survol de la ligne du projet (sur ordinateur).
  cover   : image de couverture ('assets/projets/clip.jpg')
            → sinon une affiche colorée est générée avec les deux « colors ».

SHOWREEL
  contenu.js → showreel: { video: 'assets/videos/showreel.mp4' }
  La vidéo tourne en fond de l'accueil et un bouton « Voir le showreel » apparaît.

RÉSEAUX SOCIAUX
  contenu.js → socials : un réseau n'apparaît que si son lien (url) est rempli.

RECEVOIR LES MESSAGES DIRECTEMENT
  Par défaut, le formulaire ouvre la messagerie du visiteur avec le message prêt.
  Pour les recevoir sans passer par sa messagerie : crée un formulaire gratuit sur
  https://formspree.io et colle son adresse dans contenu.js → formEndpoint.

GARDER LE SITE RAPIDE
  Vidéos : MP4 (H.264), 1080p max, compressées (HandBrake, préréglage « Fast 1080p30 »).
  Extraits de survol : 720p, 3-5 secondes, sans son.

METTRE EN LIGNE (gratuit)
  GitHub Pages, Netlify ou Vercel : dépose simplement le dossier.

AMBIANCE DE COULEURS
  contenu.js → palette : 'golden', 'teal', 'neon' ou 'lagon'.
  showPalettePicker: true affiche le sélecteur « Ambiance » pour essayer en direct ;
  mets false une fois ton choix fait.

ANIMATIONS
  anim.js utilise GSAP, ScrollTrigger et Lenis (dans assets/vendor, rien à installer).
  Si un visiteur a demandé moins d'animations dans son système, elles sont coupées.

PORTFOLIO NDIMBY — mode d'emploi
================================

LES PAGES
  index.html    l'accueil (photos cliquables autour du titre, projets sélectionnés qui défilent,
                phrase géante, clients, à propos en clap de cinéma, contact)
  projets.html  tous les projets (énorme mot « PROJETS » et rangée horizontale de tuiles)
  ancien/       l'ancien site façon bureau macOS (toujours en ligne)

LES FICHIERS
  contenu.js    ← TOUT TON CONTENU EST ICI (c'est le seul fichier à modifier)
  main.js       construit les pages (pas besoin d'y toucher)
  style.css     l'apparence (couleurs, polices, tailles)
  assets/       photos, vignettes (mini/), CV, storyboards, polices (fonts/)

CE QUI SE MODIFIE DANS contenu.js
  projects      les projets (titre, année, description, vidéo YouTube, photos…)
                video : lien YouTube / Vimeo   cover : photo de couverture
                thumb : petite version de la photo (assets/mini/) pour les tuiles
                galleries : plusieurs séries de photos dans la même fiche
  heroPhotos    les 6 photos autour du titre de l'accueil (slot = leur place, p = le projet ouvert)
  statement     la phrase géante : les mots { w: 'clips', p: 'clip-sae302' } sont cliquables
                et montrent le projet « p » au survol
  clients       la grille « Ils m'ont fait confiance » (p : projet montré au survol)
  palette       l'ambiance par défaut : lagon, golden, neon ou teal
                chaque ambiance change tout le site (fonds, textes, couleurs)
                showPalettePicker: true garde le sélecteur « Ambiance » pour les visiteurs

AJOUTER UN PROJET
  1. Ajoute un bloc dans « projects » (copie-en un existant).
  2. Mets son lien YouTube dans video (la miniature YouTube sert de couverture).
  3. Pour une photo : mets-la dans assets/projets/, indique-la dans cover,
     et si tu peux, une version réduite (900 px) dans assets/mini/ pour thumb.

RECEVOIR LES MESSAGES DIRECTEMENT
  Par défaut, le formulaire ouvre la messagerie du visiteur avec le message prêt.
  Pour les recevoir sans passer par sa messagerie : crée un formulaire gratuit sur
  https://formspree.io et colle son adresse dans contenu.js → formEndpoint.

GARDER LE SITE RAPIDE
  Photos : JPG de 1600 px au maximum. Vidéos : sur YouTube plutôt que dans le site.

ANCIEN DESIGN
  Le design précédent (ambiance Lagon, éventail de cartes) est gardé dans l'historique Git :
  étiquette « design-lagon-v1 ».
